# AXR Logistics website

Tagline: Websites. Products. AI agents. Delivered.

## Open locally
Open index.html in your browser. No installation or build step is required.
Alternatively run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Files
- index.html: page structure and content, including the inline SVG AXR logo
- styles.css: responsive layout, typography, colors, and branding
- script.js: industry selector, scripted assistant demo, and downloadable project brief
- assets/before.png: supplied business listing screenshot

## Hosting
Upload the contents of this folder to any static website host. Connecting axrlogistics.com requires configuration at your hosting and domain providers.
Google Fonts requires an internet connection; system fonts are used as fallbacks.

## Current functionality
The assistant is a scripted demonstration, not a connected AI service. The form downloads a text brief on the visitor's device; it does not submit inquiries. Live AI, inquiry delivery, and booking integrations require backend configuration.
The H N Electric redesign is illustrative, not a client claim or a live business website.
